# プローブ分子周辺残基環境取得

プローブ分子周辺残基環境取得モジュールは、MSMDシミュレーションの結果から、プローブ分子の周囲にどのような残基が存在しやすいかを解析し、可視化するためのモジュールです。このモジュールは、タンパク質とリガンドの相互作用を理解し、リガンド設計に役立つ情報を提供します。

## クラス構造と責任

プローブ分子周辺残基環境取得モジュールは、以下の主要なクラスから構成されています：

- **ResidueEnvironmentAnalyzer**：残基環境解析全体を管理するクラス
  - PMAPの読み込み
  - プローブ分子周辺の残基の特定
  - 残基環境の解析

- **ResidueProfileGenerator**：残基プロファイルの生成を担当するクラス
  - 残基環境からプロファイルを生成
  - プロファイルの正規化
  - プロファイルの保存

- **ResidueEnvironmentVisualizer**：残基環境の可視化を担当するクラス
  - 残基環境の可視化
  - 可視化結果の保存

## 主要なメソッドと機能

```python
class ResidueEnvironmentAnalyzer:
    def __init__(self, config):
        """
        残基環境解析クラスを初期化する

        Parameters
        ----------
        config : dict
            設定情報
        """
        self.config = config
        self.profile_generator = ResidueProfileGenerator(config)
        self.visualizer = ResidueEnvironmentVisualizer(config)

    def analyze(self, pmap_file, protein_file):
        """
        残基環境を解析する

        Parameters
        ----------
        pmap_file : str
            PMAPファイルのパス
        protein_file : str
            タンパク質構造ファイルのパス

        Returns
        -------
        dict
            残基環境情報
        """
        # PMAPの読み込み
        pmap = self._load_pmap(pmap_file)
        
        # プローブ分子周辺の残基の特定
        residues = self._identify_residues(pmap, protein_file)
        
        # 残基プロファイルの生成
        profile = self.profile_generator.generate(residues)
        
        # 残基環境の可視化
        visualization = self.visualizer.visualize(profile)
        
        # 結果の管理
        result = {
            'profile': profile,
            'visualization': visualization
        }
        
        return result
```

## 他モジュールとの連携ポイント

プローブ分子周辺残基環境取得モジュールは、以下のモジュールと連携しています：

- **後処理モジュール**：後処理モジュールが生成したPMAPを使用して残基環境を解析します。
- **可視化モジュール**：残基環境の可視化に可視化モジュールを使用します。

## 残基環境解析アルゴリズム

プローブ分子周辺残基環境取得モジュールでは、以下のようなアルゴリズムを使用して残基環境を解析します：

1. **PMAPの読み込み**：OpenDXフォーマットのPMAPファイルを読み込みます。
2. **タンパク質構造の読み込み**：PDBファイルからタンパク質構造を読み込みます。
3. **プローブ分子周辺の残基の特定**：PMAPの値が高い領域の周囲にある残基を特定します。
4. **残基の分類**：特定した残基をアミノ酸の種類、極性、電荷などに基づいて分類します。
5. **残基プロファイルの生成**：分類結果から残基プロファイルを生成します。
6. **統計解析**：残基プロファイルの統計解析を行います。

## 残基プロファイルの生成

残基プロファイルは、プローブ分子周辺の残基環境を定量的に表現するものです。以下のような情報が含まれます：

1. **アミノ酸組成**：プローブ分子周辺に存在するアミノ酸の種類と頻度
2. **極性残基の割合**：極性残基（Ser、Thr、Asn、Glnなど）の割合
3. **荷電残基の割合**：正電荷残基（Lys、Argなど）と負電荷残基（Asp、Gluなど）の割合
4. **疎水性残基の割合**：疎水性残基（Ala、Val、Leu、Ile、Phe、Trp、Metなど）の割合
5. **二次構造要素**：α-ヘリックス、β-シート、ループなどの二次構造要素の割合
6. **溶媒露出度**：残基の溶媒露出度の分布

## 残基環境の可視化

プローブ分子周辺残基環境取得モジュールでは、以下のような方法で残基環境を可視化します：

1. **ヒートマップ**：残基プロファイルをヒートマップとして可視化します。
2. **バープロット**：アミノ酸の種類ごとの頻度をバープロットとして可視化します。
3. **円グラフ**：残基の分類（極性、電荷、疎水性など）を円グラフとして可視化します。
4. **3D可視化**：プローブ分子周辺の残基をタンパク質構造上に3D表示します。

## 実装上の注意点

### パフォーマンス最適化

残基環境解析は計算コストが高い場合があるため、以下のような最適化が行われています：

1. **空間分割**：空間を分割して、効率的に残基を検索します。
2. **キャッシュ**：頻繁に使用するデータをキャッシュして、計算を高速化します。
3. **並列処理**：複数のプローブ分子や残基の解析を並列化して、処理を高速化します。

### 精度と感度のバランス

残基環境解析では、精度と感度のバランスが重要です。以下のような工夫が行われています：

1. **適切な閾値の選択**：PMAPの値の閾値を適切に選択して、偽陽性と偽陰性のバランスを取っています。
2. **複数のプローブの使用**：異なる性質を持つ複数のプローブを使用して、多角的に残基環境を評価しています。
3. **統計的な評価**：残基環境の統計的な有意性を評価して、信頼性の高い結果を得ています。

### 拡張性

残基環境解析モジュールは、以下のような拡張性を持っています：

1. **新しい解析方法の追加**：新しい残基環境解析方法を簡単に追加できるように設計されています。
2. **プロファイル生成方法のカスタマイズ**：残基プロファイルの生成方法をカスタマイズできます。
3. **可視化方法の拡張**：新しい可視化方法を追加するためのインターフェースが用意されています。

## 使用例

以下は、プローブ分子周辺残基環境取得モジュールの使用例です：

```python
# 設定情報
config = {
    'threshold': 0.7,  # PMAPの値の閾値
    'distance_cutoff': 5.0,  # 残基の検索距離（Å）
    'profile': {
        'amino_acid_types': True,  # アミノ酸の種類を含める
        'polarity': True,  # 極性を含める
        'charge': True,  # 電荷を含める
        'hydrophobicity': True,  # 疎水性を含める
        'secondary_structure': True,  # 二次構造を含める
        'solvent_exposure': True  # 溶媒露出度を含める
    },
    'visualization': {
        'format': 'matplotlib',  # 可視化フォーマット
        'color_scheme': 'default'  # カラースキーム
    }
}

# 残基環境解析クラスの初期化
analyzer = ResidueEnvironmentAnalyzer(config)

# 残基環境の解析
result = analyzer.analyze('path/to/pmap.dx', 'path/to/protein.pdb')

# 結果の表示
print("残基プロファイル:")
for amino_acid, frequency in result['profile']['amino_acid_types'].items():
    print(f"  {amino_acid}: {frequency:.2f}")

print("極性残基の割合:", result['profile']['polarity']['polar'])
print("荷電残基の割合:", result['profile']['charge']['positive'] + result['profile']['charge']['negative'])
print("疎水性残基の割合:", result['profile']['hydrophobicity']['hydrophobic'])

# 可視化結果の保存
with open('residue_profile.png', 'wb') as f:
    f.write(result['visualization'])
```
